1. 异常只能抛出一次

![](img\2019072701.png)

2. 捕获异常不能重复捕获同类型的异常：IllegalArgumentException是NumberFormatException的父类，抛出了IllegalArgumentException之后再抛出NumberFormatException异常就属于抛出同类，因为后者也属于前者类型。也不能重复抛出同一个异常。

![](img\2019072702.PNG)

3. 抛出异常之后的代码还会不会被执行：抛出整个函数内部的异常，如果函数内部发生异常，则函数内部异常处之后的代码都不会被执行。

![](img\2019072703.png)
