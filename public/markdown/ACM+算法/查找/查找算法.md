​    顺序查找：它是一种最简单的查找方法。基本思路是：从表的一段开始顺序扫描现行表，依次将扫描到的关键字和给定k相比较。

​    有序表查找之折半查找：折半查找是一种效率较高的查找方法。它要求线性表是有序的。它的时间复杂度是O(n log2n).

设R[low...high]是当前查找的区间，首先确定该区间的中点位置mid=(low+high)/2,然后待查找的k值与R[mid].key比较，若相等查找成功，若>将区间确定为R[mid...high]继续查找，若<将区间确定为R[low...mid]继续查找。

```cpp
int Binsearch(SeqList R,int n,KeyType k)
{
  int low=0,high=n-1,mid;
  while(low<=high)
  {
    mid=(low+high)/2;
    if(R[mid].key==k)return mid+1;
    if(R[mid].key>k)high=mid-1;
    else low=mid+1;

}
```

​    **三分查找算法**

```cpp
int BinSearch(SeqList R,int n,KeyType k)
{
    int low=0,high=n-1,mid,mid1;
    while(low<=high)
    {
        mid=(high-low)/3+low;
        mid1=(high-low)*2/3+low;
        if(R[mid].key==k)
            return mid+1;
        if(R[mid].key>k)
            high=mid-1;
        else
        {
            low=mid+1;
            if(R[mid1].key==k)
                return mid1+1;
            if(R[mid1].key>k)
                high=mid1-1;
            else
                low=mid1+1;
        }
    }
    return 0;
}
```
