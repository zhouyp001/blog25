## 离线安装包安装方法（推荐）

1.下载NET Framework 3.5.zip文件包（网上找一下）

2.将下载的NET Framework 3.5.zip解压，解压后如下图！

![Windows10系统安装 .NET Framework 3.5](img/2e2eb9389b504fc213b03077efdde71191ef6dd1.png)

3.将解压得到【sxs】文件夹复制到C盘根目录（就是直接拖进C盘,用完后可以删除）

![Windows10系统安装 .NET Framework 3.5](img/b151f8198618367a9753fcaf24738bd4b21ce5ee.png)

4【右键】>【以管理员身份运行】NET Framework 3.5，完成

温馨提示：一定要【右键】以管理员身份运行NET Framework 3.5！

![Windows10系统安装 .NET Framework 3.5](img/8718367adab44aed61943d96b91c8701a08bfbee.png)

5随后会出现一个黑框，等到100%就完成了！有时速度会很快，闪一下就过去了。

![Windows10系统安装 .NET Framework 3.5](img/6f061d950a7b0208fd3c984a68d9f2d3562cc8a0.jpg)

6第一种方法完成！不明白的地方看说明！

![Windows10系统安装 .NET Framework 3.5](img/f7246b600c338744b43cfbd35b0fd9f9d62aa0a0.jpg)

## 方法2：在线安装方法（不推荐）

1. 如图，右键点击【Windows标】

   ![Windows10系统安装 .NET Framework 3.5](img/0b46f21fbe096b63a97ab6ff06338744ebf8ac3a.png)

2. 点击【功能和应用】

   ![Windows10系统安装 .NET Framework 3.5](img/4d086e061d950a7b383ea66b00d162d9f2d3c912.png)

3. 现在window10会进入如图的界面，滚动到最下面点击【应用和程序】

   ![Windows10系统安装 .NET Framework 3.5](img/a50f4bfbfbedab640e11a56ffd36afc379311e39.png)

4. 点击【启用或关闭Windows功能】

   [![Windows10系统安装 .NET Framework 3.5](img/5243fbf2b2119313ce20171f6f380cd791238d3a.png)

5. 然后如图，勾上图示选项

   ![Windows10系统安装 .NET Framework 3.5](img/d788d43f8794a4c297560f8404f41bd5ad6e392c.png)

6. 最后点击【确定】，然后就等着系统自己安装完成！

   ![Windows10系统安装 .NET Framework 3.5](img/54fbb2fb43166d220311c23b4c2309f79052d23f.png)
